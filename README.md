# FPS 竞技场（Web FPS Arena）

网页版第一人称射击游戏：**单个 HTML 文件 + 本地 Three.js 库**，无需构建工具，双击即可运行。

- 🔗 在线试玩：https://studyguy.github.io/FPS_web/
- 📁 本仓库：https://github.com/studyguy/FPS_web

## ✨ 特性

- **玩家**：Pointer Lock 鼠标视角、WASD 移动、空格跳跃（轻点小跳/长按高跳）、Shift 加速跑（消耗耐力）、C 蹲伏、耐力系统、重力与碰撞（防穿墙）、脱战回血、落地反馈、受击方向指示、低血量警示、死亡慢镜头
- **武器**：自动步枪（9 发/秒）、枪口火焰、后坐力恢复、准星扩散、右键瞄准、R 换弹、爆头 2 倍伤害
- **敌人（4 类，按波次解锁）**：突击兵 / 疾行者 / 重装兵 / 射手，攻击带前摇红光预警、突进、击退
- **受击规则**：0.4s 无敌帧（防围攻瞬秒）、红晕 + 白闪 + 震动 + 音效
- **波次系统**：构成逐波升级（第 7 波起出现远程射手），血量/伤害/移速按波缩放，波间补给弹药
- **场景**：环形能量竞技场、**每波程序化生成的可变地形**（低台/跳台/矮墙/桥洞/能量高台渐进解锁）、实时阴影、渐变天空、Web Audio 合成音效与背景音乐

### 🗺️ 地形机制（结合跳跃与蹲伏 · 防无敌点设计）

- **低台 / 跳台（0.6m）**：跳跃可上、东侧跳台链可连跳机动；近战仍可命中（0.6m < 高度差阈值 0.8m）→ 平台是"动"的战术位，不是安全屋
- **中央能量高台（1.2m）**：第 7 波与射手同步解锁的制高点——可俯射，但射手弹道可命中、被近战围台只能跳下突围（高风险高回报）
- **矮墙（1.35m）**：蹲姿完全隐蔽（敌人视线三维瞄准眼睛，射手看不见你）、站姿露头挨打、跳跃可翻越、**墙顶不可站立**（防无敌点）
- **桥洞（顶高 1.3m）**：蹲姿通行，洞内无法站起；可躲射手弹道与视线
- **每波换图**：波间用波次号作种子重建地形（同波可复现），木箱/柱子/矮墙布局随机；出生点有绿色引导箭头
- 生成硬约束：无重叠、无死路（网格 BFS 可达性校验）、平台不落刷怪环、**可站立地形高度与威胁联动（w<7 无 ≥0.8m 站立点）**、坏图自动回退上一波

## 🚀 快速开始

| 方式 | 操作 |
|---|---|
| 直接游玩 | 双击 `fps.html`（现代浏览器均可，`three.min.js` 为本地兜底，离线可用） |
| 本地服务器 | `python -m http.server 8123` 后访问 http://127.0.0.1:8123/fps.html |
| 在线游玩 | https://studyguy.github.io/FPS_web/ （GitHub Pages 自动部署 main 分支） |

## 🎮 操作

| 按键 | 功能 |
|---|---|
| WASD | 移动 |
| 鼠标 | 视角（点击画面锁定，灵敏度可在暂停界面调节） |
| 左键 | 射击（按住连发，开火自动解除冲刺） |
| 右键 | 瞄准（移速降低） |
| 空格 | 跳跃（轻点小跳、长按高跳，蹲伏中起跳自动站起） |
| Shift | 加速跑（消耗耐力） |
| C | 蹲伏（蹲伏可躲避射手弹道） |
| R | 换弹 |
| M | 声音开关 |
| 方向键 | 转视角（指针锁定不可用时的备用方案） |
| Esc | 暂停 |

> 耐力：冲刺 30/s、跳跃 5/次；停止消耗 0.8s 后以 40/s 回复，耐力低于 15 无法冲刺（HUD 耐力条红闪提示）。

## 👾 敌人规则速查

| 类型 | 解锁 | HP | 移速 | 攻击 | 伤害 | 冷却 | 范围 | 击杀分 |
|---|---|---|---|---|---|---|---|---|
| 🔴 突击兵 | 第1波 | 100 | 2.6 | 挥击+突进 | 10 | 0.9s | 2.6 | 100 |
| 🟠 疾行者 | 第3波 | 60 | 4.3 | 扑咬+突进 | 6 | 0.7s | 1.9 | 130 |
| ⚫ 重装兵 | 第5波 | 300 | 1.6 | 重击+击退玩家 | 22 | 1.4s | 2.8 | 250 |
| 🟣 射手 | 第7波 | 80 | 2.0 | 远程光球（可躲可挡） | 8 | 2.2s | 射程22 | 160 |

- 攻击流程：追击 → **前摇红光预警**（可躲）→ 命中判定 → 突进 → 硬直 → 冷却
- 波次构成（1~10 波）：5G → 7G → 7G2R → 8G3R → 8G3R1B → 9G4R2B → 9G4R2B1S → 10G5R2B2S → 11G5R3B2S → 12G6R3B3S；11 波起公式增长，单波上限 26 只
- 数值成长：HP ×(1+0.12(波-1)) 上限×3；伤害 ×(1+0.06(波-1)) 上限×1.8；移速 +0.05/波 上限×1.5
- 玩家：HP 100，受击无敌帧 0.4s，脱战 6s 后回血 6/s

## 🛠 调试工具

浏览器 F12 控制台可用：

```js
__game.debug.spawnWave(7)              // 直接跳到第 7 波
__game.debug.teleportEnemyNear('brute', 3)  // 传送重装兵到面前
__game.debug.heal()                    // 回满血
__game.debug.refillStamina()           // 回满耐力
__game.debug.toggleGod()               // 无敌模式开关
__game.debug.setSens(3.5)              // 设置鼠标灵敏度
__game.debug.regenerateMap()           // 手动重抽当前地形（随机种子）
```

## ⚙️ 技术说明

- Three.js r152（本地 `three.min.js` 优先，失败时回退 jsdelivr / cdnjs / bootcdn / unpkg）
- 对象池：子弹 60、敌人 26、粒子 240、敌人弹幕 40
- 主循环 `requestAnimationFrame`，含防崩溃安全网（单帧异常不中断循环）
